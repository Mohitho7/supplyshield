What the comparison tells us

Explain the trade-off in plain language.

A
Aggregate performance can hide priority differences

Agent-assisted and optimized strategies fulfill the same total number of units, but assign those units differently across products.

B
The best score is not the same thing as lowest cost

Candidate feasibility, service performance, recovery timing, and documented priority weights affect the ranking.

C
Keep infeasible baselines visible—but clearly disqualified

Useful for explaining why static rules fail, not for suggesting the planner can choose them.

Model scope

Put assumptions where the user interprets the numbers.

  • Deterministic demand and fixed 21-day evaluation horizon.
  • Unmet daily demand is period-specific; this is not a cumulative backlog queue.
  • Downstream factory/DC transfer constraints are not enforced.
  • No real-time telematics, supplier API, or ERP dispatch.
  • All numbers shown here are a saved reference snapshot, not live API results.
